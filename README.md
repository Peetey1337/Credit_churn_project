## Credit Card Fraud Detection – SQL + Python

### Project overview

End-to-end data analytics project using MySQL and Python.
The project covers:

- database creation
- CSV ingestion
- SQL-based analysis
- Python-based analytics

### Dataset

Credit Card Fraud Detection dataset (Kaggle)

### How to run

1. Install MySQL Server
2. Create virtual environment
3. Install requirements:
   pip install -r requirements.txt
4. Create `.env` based on `.env.example`
5. Run SQL scripts from `/sql`
6. Run data loader:
   python src/load_data.py
7. Run analysis scripts
